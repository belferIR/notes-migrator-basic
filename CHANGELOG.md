# Changelog

## 1.0.0 – 2026-11-10
First public release, based on Notes Migrator 0.5.1 (author's private version).
- My Library only (group libraries, change history and `#autor/` tags removed).
- Polish and English: menus, settings, file/folder names and Markdown headings; *auto* follows Zotero's language.
- Settings pane: vault, language, annotated PDF copy on/off, own file name for each of the 8 Zotero highlight colours, sample colour set.
- Automatic updates through `updates.json`.
